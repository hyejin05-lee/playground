##산출물: `docs/2_OOA/UseCase_Model.md`
##분석항목
- 시스템 요구사항 문서를 기반으로 Use case analysis를 수행해서 기능에 대한 Use case diagram (UCD)을 작성한다.
- 각 Use case (UC)를 표 형태로 작성한다.
- system sequence diagram (SSD) 을 작성한다.
##체크리스트
- Use case diagram에 System의 boundary를 표시한다
- System Context Diagram 과 I/O 내용이 일치하는 Use case diagram을 작성한다.
- UC와 SSD는 1:1 맵핑된다.
- SSD에 `:system` 객체가 있어야 한다.
- SSD의 외부 Actor는 Use case diagram 의 내용과 일치해야 한다.
