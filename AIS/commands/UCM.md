# Use Case Model Command
- Use Case Diagram(UCD)를 먼저 그린다.
- System의 Boundary(Context)를 명확히 작성한다. 
- Use Case는 표 형태로 생성한다.
- 시스템 요구사항에 맞는 Use Case와 그에 대응하는 SSD(System Sequence Diagram)을 작성한다.
- SSD에는 `:System`에 대한 actor의 요청을 포함한다.
- UCD의 시스템 내부/외부 경계가 Domain Model과 일치하도록 한다.
- 산출물: `docs/UseCase_Models.md`
